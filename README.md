# صلاتك - Salatak

تطبيق متابعة قضاء الصلاة.

## المميزات
- تسجيل دخول بالبريد أو الهاتف (بدون كلمة مرور)
- اختيار المدة (يوم/أسبوع/شهر/سنة/مخصص)
- جدول قضاء الصلاة مع 5 أعمدة (الفجر، الظهر، العصر، المغرب، العشاء)
- حفظ تقدم كل مستخدم على حدة
- زر إضافة يوم جديد
